# Salamander Project

## By Jason and Orion

This is the frontend for the Salamander Project, which uses [centroid-finder](https://github.com/F00dDemon/centroid-finder), a project used to find the center of the largest connected region of an image / video. For this part, the Java jar and the server API calls are interfaced within a React-based web page, where you can view a list of available videos, playback available videos, preview the binarization and centroid views of the video to process, and export a csv of all largest centroids from the video. 

##Setup

To set up this project, you will need to have cloned this [repository](https://github.com/F00dDemon/centroid-finder) beforehand and have it running before you run this one!

1) Clone the repository and navigate to it.
2) ```npm i``` to install the necessary node packages.
3) ```npm run dev```!
