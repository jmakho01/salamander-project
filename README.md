# Salamander Project

## By Jason and Orion

This is the frontend for the Salamander Project, which uses [centroid-finder](https://github.com/F00dDemon/centroid-finder), a project used to find the center of the largest connected region of an image / video. For this part, the Java jar and the server API calls are interfaced within a React-based web page, where you can view a list of available videos, preview the binarization and centroid views of the video to process, and export a csv of all largest centroids from the video.

Color Palette: #FFFFFF, #E1E5EB, #8B9FC6, #445FEF, #140F0A

## Setup

To set up this project, you will need to have cloned this [repository](https://github.com/F00dDemon/centroid-finder) beforehand and have it running before you run this one!

1) Clone the repository and navigate to it.
2) ```npm i``` to install the necessary node packages.
3) ```npm run dev```!

## Additional Feature

The ability to playback videos has been implemented. To access this, press the Playback button on the Video list page, which will lead you to a page where the video will load and be viewable.
